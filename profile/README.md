## ✨ What We Do

VeilData builds **secure data pipelines for AI**, starting with ultra-fast PII redaction.

We believe every organization should be able to use LLMs and automation **without leaking sensitive data**—in logs, prompts, responses, or training pipelines.

Our platform is built for:

- AI teams integrating LLMs into production  
- Compliance-sensitive products (fintech, health, insurance)  
- Engineering orgs that need security without friction  

---

## 🧱 Core Components

### **VeilData CLI (Public)**
A fast, local-first redaction tool for developers and pipelines.

- ⚡ Fast, configurable masking  
- 🤖 NER + rule-based detection  
- 📦 Works with Docker or `uv run`  
- 🛠️ Perfect for logs, files, batch pipelines  

**Repo:** https://github.com/VeilData/veildata

---

### VeilData Platform (Early Access)

A secure data layer for AI systems — combining high-throughput redaction pipelines with a modern control plane to manage everything end-to-end.

### **Core Capabilities**
- Ultra-fast PII redaction (rule-based + ML-driven)  
- Real-time and batch data processing  
- Safe-compute pipelines for LLMs and agents  
- Workspace and policy management  
- Audit trails & compliance logging  
- Access controls and team permissions  

### **Under the Hood**
- Rust microservices for low-latency transforms & APIs  
- Next.js + TypeScript dashboard for configuration and governance  
- Docker & Kubernetes deployment-ready
